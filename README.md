# CRC Workflow Hub (demo)

Next.js 15 (App Router) + React 19 + TypeScript + Tailwind v4.

```bash
npm install
npm run dev     # http://localhost:3000
```

- Login is for show only; nothing is stored. All data is in-memory mock data (resets on refresh).
- Theme: #012169 + shades of blue, sharp corners everywhere, Bangla Sangam MN font (installed on macOS/iOS; other systems fall back to a sans-serif).
- Flow: Login -> Landing -> Study -> Participant -> Visit data-capture pop-up.
